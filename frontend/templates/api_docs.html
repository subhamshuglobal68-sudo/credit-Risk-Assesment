API Integration Docs

Integrate CREA AI credit scoring, fraud alerts, and explainability features directly into your core banking services.

Service Endpoint

The CREA scoring service exposes a RESTful POST endpoint that accepts raw applicant profiles, performs sanity checks, runs anomaly and fraud detection, and returns risk assessments.

POST http://127.0.0.1:5000/api/predict

Request Payload Structure

Submit applicant characteristics using a flat JSON object. Alternate indicators are optional, but activate automated creditworthiness boosts if provided.

{
  "applicant_id": "APP-9831A",
  "age": 34,
  "job": "skilled employee",
  "income": 85000.00,
  "loan_amount": 25000.00,
  "existing_debt": 5200.00,
  "rent_on_time": "On Time (Last 12 Months)", // Optional alternative data
  "utility_on_time": "On Time (Last 12 Months)", // Optional alternative data
  "recharge_consistency": "Consistent Monthly Recharge", // Optional alternative data
  "currency": "INR"
}

Integration Code Snippets

cURL

curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "applicant_id": "APP-981",
    "age": 34,
    "income": 85000,
    "loan_amount": 20000,
    "existing_debt": 3000
  }'

Python (requests)

import requests

url = "http://127.0.0.1:5000/api/predict"
payload = {
    "applicant_id": "APP-981",
    "age": 34,
    "income": 85000,
    "loan_amount": 20000,
    "existing_debt": 3000
}
resp = requests.post(url, json=payload).json()
print("Score:", resp["risk_score"])

JavaScript (fetch)

const payload = {
  applicant_id: "APP-981",
  age: 34,
  income: 85000,
  loan_amount: 20000,
  existing_debt: 3000
};

fetch('http://127.0.0.1:5000/api/predict', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify(payload)
})
.then(res => res.json())
.then(data => console.log(data));

Response Schema Definitions

Field KeyData TypeDescription
risk_scoreIntegerThe 0-1000 credit score value mapped from default probability bounds.
risk_score_100Integer0-100 creditworthiness score (100 is best, 0 is worst).
default_risk_score_100Integer0-100 probability metric (100 is worst, 0 is best).
probability_of_defaultFloatRaw statistical output (0.0 to 1.0) returned from target ML model.
risk_categoryStringEvaluated category: LOW, MEDIUM, or HIGH.
recommendationStringPolicy recommendation: APPROVE, REVIEW, or REJECT.
fraud.is_suspiciousBooleanTrue if logical red flags (income inflation, etc.) are triggered.
anomaly.is_anomalousBooleanTrue if isolation forest identifies applicant as population outlier.
