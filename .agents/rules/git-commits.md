# Git Auto-Commit and Remote Sync Rule

Whenever changes, additions, or modifications are made to this project:
1. Ensure files comply with `.gitignore`.
2. Stage modified and newly created files with `git add .`.
3. Commit all changes with a clear, concise commit message.
4. Push to remote repository (`origin main`: `https://github.com/subhamshuglobal68-sudo/credit-Risk-Assesment`).
5. Ensure the working tree remains clean and fully synced with GitHub.
